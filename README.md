# netscope

## 中文说明

### 远程安装
你可以直接从远程仓库安装 `netscope`：

```bash
git clone git@github.com:lbyxunxunnini/netscope.git
cd netscope
```

如果你使用 HTTPS：

```bash
git clone https://github.com/lbyxunxunnini/netscope.git
cd netscope
```

### 远程依赖
如果项目依赖远程包源，请先安装依赖再启动：

```bash
pnpm install
# 或 npm install
# 或 yarn install
```

如果依赖里包含 Git 仓库地址，请确保当前环境可以访问对应远程仓库（SSH Key 或 HTTPS Token 已配置）。

## English

### Remote Installation
You can install `netscope` directly from the remote repository:

```bash
git clone git@github.com:lbyxunxunnini/netscope.git
cd netscope
```

If you prefer HTTPS:

```bash
git clone https://github.com/lbyxunxunnini/netscope.git
cd netscope
```

### Remote Dependencies
If the project relies on remote package registries, install dependencies first:

```bash
pnpm install
# or npm install
# or yarn install
```

If any dependency is pulled from a Git URL, make sure your environment can access that remote source (SSH keys or HTTPS token configured).
